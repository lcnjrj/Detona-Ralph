**JSGame Detona Ralph**
Detona‑Ralph é um jogo simples em JavaScript que demonstra lógica de interação, manipulação do DOM e conceitos básicos de física de jogo. Foi desenvolvido como projeto de portfólio para mostrar habilidades em HTML, CSS e JavaScript, além de práticas de versionamento com Git.
Alterei cor do fundo para poder diferenciar do código original.

Tecnologias
HTML5
CSS3
JavaScript (ES6+)
Git / GitHub

Hospedagem: GitHub Pages (deploy estático)

Funcionalidades
Controles básicos para movimentação do personagem.
Colisões simples entre elementos do jogo.
Sistema de pontuação e reinício de partida.
Layout responsivo para telas pequenas.
Arquitetura de código organizada em módulos simples para facilitar leitura e manutenção.

Como executar localmente:
Clone o repositório

git clone https://github.com/lcnjrj/Detona-Ralph.git
cd Detona-Ralph

Abra o arquivo index.html no navegador ou use um servidor local simples

# com Python 3
python -m http.server 8000
# depois abra http://localhost:8000

Estrutura do repositório
index.html — página principal do jogo
css/ — estilos e responsividade
js/ — scripts do jogo (entrada, lógica, colisões, pontuação)
assets/ — imagens e sons usados no jogo
README.md — este arquivo
